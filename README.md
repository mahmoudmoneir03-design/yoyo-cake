# دفتر التورت (Flutter)

تطبيق أندرويد لإدارة طلبات التورت: بيانات العملاء، العربون والدفعات، تكلفة الخامات والوصفات، المصروفات، وتقارير المبيعات وصافي الربح.
البيانات بتتحفظ على الموبايل نفسه (من غير إنترنت).

## إزاي تطلع ملف APK (من غير ما تنزّل أي حاجة على جهازك)

1. اعمل حساب مجاني على github.com.
2. اعمل Repository جديد (اسمه مثلاً `dafter-tort`) وارفع عليه كل محتويات المجلد ده، بما فيها مجلد `.github` المخفي.
3. افتح تاب **Actions** في الـ Repository وادوس على **Build APK** ثم **Run workflow**.
4. استنى حوالي ٥ - ١٠ دقايق. لما يخلص ادخل على آخر تشغيل ونزّل **dafter-tort-apk** من قسم Artifacts.
5. فك الضغط وانقل `app-release.apk` لموبايلك وثبّته (لازم تسمح بالتثبيت من مصادر غير معروفة).

## لو عندك Flutter على جهازك

```
flutter create --platforms=android --org com.dafter --project-name dafter_tort .
flutter pub get
flutter run            # تجربة على موبايل أو محاكي
flutter build apk --release
```

## إزاي تحسب التكلفة

1. من تاب **المكونات > الخامات** سجّل كل خامة: الكمية اللي اشتريتها وسعرها (مثلاً سكر ١٠٠٠ جرام بـ ٤٠ جنيه).
2. من تاب **الوصفات** اعمل وصفة بكميات الخامات (مثلاً تورتة شوكولاتة ٢ كيلو).
3. في الطلب اختار "من وصفة جاهزة" أو ضيف خامات بإيدك. التكلفة بتتحسب بسعر الخامة وقت الطلب، فتغيير الأسعار بعد كده مبيغيّرش أرباح الطلبات القديمة.
4. صافي الربح = المبيعات − (تكلفة الخامات والتغليف والتوصيل) − المصروفات العامة.
